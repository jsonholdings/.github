# JSON Holdings

JSON Holdings LLC is a privately held Ohio company that owns and operates several small
software and services brands. Most of what we build is internal infrastructure, shared
across those brands rather than sold on its own.

## What we publish

When a piece of that infrastructure is useful outside JSON Holdings on its own terms, we
publish it here under an open-source license, rather than keeping it to ourselves.
